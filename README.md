# Практична робота №1
## Вступ до IoT та SMART-технологій

**Варіант 1 — Розумна теплиця**

### Мета роботи

Спроєктувати IoT-систему автоматичного вирощування рослин для теплиці площею 200 м². Система повинна забезпечувати автоматичний контроль основних параметрів мікроклімату та керування обладнанням теплиці.

### Основні завдання системи

Система «Розумна теплиця» повинна забезпечувати:

- контроль температури повітря;
- контроль вологості повітря;
- контроль вологості ґрунту;
- контроль рівня освітленості;
- контроль концентрації CO₂;
- автоматичне керування поливом;
- керування вентиляцією;
- керування додатковим освітленням;
- керування системою обігріву;
- збереження працездатності системи у разі втрати зв'язку з хмарою.

### Принцип роботи

Датчики, розташовані в теплиці, періодично вимірюють параметри навколишнього середовища. Отримані дані передаються на локальний контролер. Контролер аналізує показники та керує виконавчими пристроями.

Наприклад, якщо вологість ґрунту стає нижчою за встановлене значення, контролер вмикає систему поливу. При підвищенні температури вмикається вентиляція, а при недостатньому освітленні — система досвітлення.

Основні рішення повинні прийматися локально, щоб теплиця могла продовжувати автоматичну роботу навіть у випадку втрати з'єднання з хмарним сервісом.
